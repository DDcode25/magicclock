# Техническое задание: прошивка Magic Box FW для GeekMagic SmallTV Pro

Документ описывает, что должна делать прошивка и что уже сделано. Обновляется вместе с кодом.

## 1. Цель

Своя прошивка для часов GeekMagic SmallTV Pro, которая:
- повторяет функции заводской прошивки (V3.4.88EN);
- остаётся совместимой с её настройками и веб-интерфейсом, чтобы перейти на неё без потери данных;
- добавляет новые приложения. Первое из них — карта воздушных тревог Украины.

## 2. Аппаратная платформа

Всё ниже определено разбором заводской прошивки и проверено на устройстве.

| Узел | Значение |
|---|---|
| МК | ESP32-D0WD-V3 rev 3, 2 ядра, 240 МГц, **без PSRAM** (~230 КБ свободной RAM) |
| Флеш | 8 МБ, DIO, 80 МГц |
| Дисплей | ST7789 240×240, SPI3 (VSPI): SCLK 18, MOSI 23, CS 15, DC 2, RST 4, **27 МГц**; порядок цветов BGR, инверсия включена. MISO (19) в заводской конфигурации есть, но чтение с панели не работает (возвращает 0) |
| Подсветка | GPIO25, LEDC канал 0, 5 кГц, 8 бит, **инверсная** (255 = выкл) |
| Кнопка | Ёмкостный сенсор сверху, GPIO32 (T9); в покое ~101, при касании 79–93. Нажатие — ниже 92 % уровня покоя, отпускание — выше 95 %, среднее по 3 замерам, уровень покоя медленно подстраивается |
| USB | Только питание, UART недоступен |

### Таблица разделов (заводская, не менять)

| Раздел | Смещение | Размер |
|---|---|---|
| nvs | 0x9000 | 20K |
| otadata | 0xE000 | 8K |
| app0 / app1 | 0x10000 / 0x230000 | 2176K каждый |
| spiffs (LittleFS) | 0x450000 | 3776K |

## 3. Ограничения

- **Прошивка только по OTA** (`POST /update`, поле `firmware`), восстановления через UART нет. Поэтому:
  - Wi-Fi, точка доступа и `/update` должны работать в любой версии;
  - фреймворк — Arduino-ESP32 2.0.x (ESP-IDF 4.4), совместимый с заводским загрузчиком;
  - LittleFS никогда не форматируется автоматически;
  - `/.sys/config.json` (Wi-Fi) не удаляется ни сбросом, ни через `/delete`.
- **Мало памяти:** без PSRAM большие картинки и ответы API обрабатываются потоково или с фильтрами.
- **Совместимость:** формат файлов `/.sys/*.json` и ответы API совпадают с заводскими.

## 4. Архитектура

PlatformIO, `custom-fw/firmware/`:

| Модуль | Назначение |
|---|---|
| `store` | LittleFS, чтение и запись `/.sys/*.json`, разобранные настройки `Settings` |
| `net` | Wi-Fi STA, запасная точка доступа с captive portal, mDNS `smalltv-pro.local`, NTP и часовой пояс |
| `web` | HTTP API (раздел 5), встроенный веб-интерфейс, OTA, дамп флеша. Работает в **отдельной задаче на ядре 0**, чтобы отдача файлов (веб-интерфейс грузит все GIF как миниатюры) не останавливала экран; обработчики не рисуют сами — `ui::message()` ставит сообщение в очередь экранного цикла |
| `ui` | Дисплей, подсветка и ночной режим, сенсорная кнопка, переключение приложений |
| `apps.h` | Реестр приложений (ключи и индексы как в заводском интерфейсе) |
| `alerts`, `alerts_parse` | Приложение «Карта тревог» |
| `weather`, `clock`, `pictures` | Приложения «Погода», «Годинник», «Картинки» |
| `widgets` | Общие элементы экрана (значок Wi-Fi) |
| `ukraine_map.h` | Контуры областей и районов (Меркатор, 1/8 px), таблица районов (ключ NEPTUN, название, старое название, область); генерируется `tools/gen_ukraine_map.py`, данные определены в одной единице трансляции (`UKRAINE_MAP_DEFINE` в `alerts_parse.cpp`) |
| `tools/embed_web.py`, `tools/ui_patch.py` | Сборка веб-интерфейса: заводской `web/stock_index.html` + патчи Magic Box FW → gzip в прошивку |

`custom-fw/probe/` — диагностическая прошивка: дамп флеша, тест дисплея и сенсора, `/boot_other`.

## 5. HTTP API

Совместим с заводским. Ответ на успешный `/set` — ровно `OK`.

| Запрос | Действие |
|---|---|
| `GET /` | Веб-интерфейс (заводской + вкладка Alerts) |
| `GET /set?...` | Сохранение настроек в `/.sys/*.json` и действия (таблица ниже) |
| `GET /v.json` | `{"m":"GeekMagic SmallTV-PRO","v":"Magic Box FW x.y.z"}` |
| `GET /space.json` | `{"total":..,"free":..}` LittleFS |
| `GET /wifi.json` | Скан сетей `{"aps":[{"ss","r"(%),"e"(0/1)}]}` |
| `GET /wifisave?s=&p=` | Сохранить Wi-Fi в `config.json`, ответ `saved`, перезагрузка |
| `GET /filelist?dir=` | HTML-таблица файлов, как у заводской прошивки |
| `POST /doUpload?dir=` | Загрузка файла (поле `update`), ответ `OK` |
| `GET /delete?file=` | Удаление файла |
| `GET/POST /update` | OTA-обновление |
| `GET /flash?offset=&size=` | Сырой дамп флеша (бэкап) |
| `GET /alerts.json` | Состояние карты тревог (раздел 6.2) |
| `GET /touch.json` | Сенсорная кнопка: значение, уровень покоя, порог, счётчики касаний |
| `GET /state.json` | Текущее приложение и показывается ли сообщение |
| `GET /weather.json` | Текущая погода и ошибка загрузки |
| `GET /outage.json` | График отключений: подочередь, получасовые слоты сегодня/завтра, ошибка |
| `GET /pic.json`, `/gifcheck?file=&n=` | Диагностика «Картинок» |
| остальное | Файлы из LittleFS (`/.sys/*.json`, `/image/...`) |

Действия `/set`: `page=±1` (листать), `enter=-1`, `open_app=<Name>`, `reboot=1`, `reset=1` (удаляет настройки, **кроме Wi-Fi**), `clear=image|gif`.

Настройки `/set` → файл:

| Параметры | Файл |
|---|---|
| `brt` (%) | `brt.json` (хранится `255 − %`, строкой) |
| `t1,t2,b1,b2,en` | `timebrt.json` (ночной режим; `b2` хранится как `255 − %`) |
| `theme`, `app_<key>` | `app.json` (стартовое приложение, включённые приложения) |
| `hc,mc,sc` / `hour` / `day` / `tz_mode,tz_offset` / `ntp` | `timecolor` / `hour12` / `day` / `tz` / `ntp.json` |
| `cd1,cd2,nickname,interval` / `w_u,t_u,p_u` / `key` / `gif` | `city` / `unit` / `key` / `gif.json` |
| `c_theme`, `c_chart`, `kline`, `cin*`, `cn*`, `c_*`, `ani`, `rot_i` | Bitcoin: `c_theme`, `c_chart`, `k`, `coin2`, `cr.json` |
| `g_theme`, `g_range`, `gin*`, `g_*` | CoinGecko: `g_theme`, `cg_range`, `cgk.json` |
| `st_chart`, `st_kline`, `c0..9`, `cn0..9`, `s_*` | Акции: `st_chart`, `stk`, `stock2.json` |
| `gif_loop,i_i,autoplay,album_path,album_autoplay` | `album.json` |
| `ip,m_i` / `delay` | `monitor.json` / `delay.json` |
| `up_fg..pct_down_bg` / `dec_sep,thous_sep` | `ccolor.json` / `sep.json` |
| `al_src,al_token,al_i,al_home` | `alerts.json` (Magic Box FW) |

### Світло (графік відключень)

- **Полтава — официальный источник** (по умолчанию, `src: "poe"`): `https://www.poe.pl.ua/customs/dynamicgpv-info.php`
  — та же вставка, что на сайте Полтаваобленерго (найдена в коде khajiitvaper2017/outage-pwa). HTML ~21 КБ:
  на каждый день блок с датой «<b>27 жовтня 2026 року</b>» и таблица 6 очередей × 2 подочереди × 48 получасов,
  ячейки `light_1` — є, `light_2` — немає, `light_3` — можливо. С 27.10.2026 вёрстка новая (~180 КБ): строка
  начинается с `<td class="gpv-q">1.1</td>`, ячейки `gpv-c gpv-s1|2|3` (те же значения). Парсер принимает оба
  варианта. Разбирается потоково (`outage::PoeParser`, тест на ПК `test/poe_parse_test.cpp`), даты блоков
  сопоставляются с сегодня/завтра по часам устройства.
- Неудачное обновление не прячет график: на экране остаётся последний график за сегодня, ошибка видна в
  `/outage.json`. После полуночи вчерашний график не показывается («графік застарів») до новой загрузки.
  Причина перехода: копия `yaroslav2901` 27.10.2026 отставала от официального графика (1.1: копия 08:00–09:00,
  официально 08:00–09:30 и т. д.).
- Другие области: открытые JSON-копии сайтов облэнерго (как в проекте svitlobude): `yaroslav2901/OE_OUTAGE_DATA`
  (12 облэнерго) и `Baskerville42/outage-data-ua` (ДТЕК: Киев, Киевская, Днепр, Одесса),
  `raw.githubusercontent.com` по HTTPS. Формат: `fact.today`, `fact.data[<сутки>]["GPV1.1"]["1".."24"]` =
  yes / no / first / second / mfirst / msecond (первая/вторая половина часа; m — возможное отключение).
- Файлы до 300 КБ (Киев), поэтому разбор потоковый с фильтром только нужной подочереди (`outage_parse.h`,
  тест на ПК `test/outage_parse_test.cpp`). TLS-поток читается через блокирующий читатель (иначе ArduinoJson
  получал `EmptyInput` между TLS-записями).
- Настройки — вкладка «Світло», `/.sys/outage.json` `{"src":"poe","grp":"1.1","i":10}`
  (`/set?out_src=&out_grp=&out_i=`); по умолчанию Полтава, 1.1 (на ней ведётся отладка).
- Экран — «улитка» как на карточках облэнерго, на чёрном фоне: одна полоса шириной 25 px делает два витка за
  сутки сверху по часовой (сектор на полчаса), её внутренний радиус растёт на 1,08 px за полчаса (0:00 — 37 px,
  12:00 — на виток дальше, 24:00 — ещё на виток, отсюда «порожек» сверху), зазор 1 px. Внешний край — 114 px
  (саму спираль не увеличивать; толщина полосы — за счёт внутреннего радиуса).
  Зелёный — світло є, розовый — відключення, жёлтый — можливе. Отметки часов и получасов на внутреннем краю,
  подписи всех часов 0–23 (жирные цифры 16 px, чёрные, с двойной прорисовкой со сдвигом 1 px), белая отметка текущего времени (раз в минуту).
  В центре столбиком (цифры могут немного заходить на полосу — так решено ради толщины полосы): подочередь (28 px), «-X» розовым (часы без света вместе с
  возможными) и «+Y» зелёным (со светом) — жирные цифры 24 px; при показе завтра — «завтра» в левом
  верхнем углу; при ошибке загрузки — ошибка вместо часов. Долгое касание — завтра (когда
  опубликован). Значок Wi-Fi в углу.
- `/outage.json` — состояние, полчаса сегодня и завтра (`+` есть, `-` нет, `?` возможно).

### Картинки

- Файлы JPG/JPEG/GIF из `/image` (без подпапок), по имени; меньше 240×240 — по центру, JPG больше — уменьшается в 2/4/8 раз.
- `album.json`: `autoplay` 1 — слайд-шоу (JPG держится `i_i` с, GIF играет `gif_loop` раз), иначе показывается
  `path` (или первый файл), GIF по кругу. Долгое касание — следующий файл.
- JPG: TJpg_Decoder; GIF: AnimatedGIF, потоково из LittleFS, построчно на экран, с учётом прозрачности.
  Декодер GIF (~20 КБ) создаётся только пока приложение открыто. Непрозрачный кадр выводится одним окном
  (`setAddrWindow` на первой строке, дальше только пиксели): при окне на каждую строку и SPI 40 МГц часть кадров
  рассыпалась в полосы, хотя декодирование на устройстве совпадало с ПК бит в бит (проверка `/gifcheck`).
- Диагностика: `/pic.json` (кадры, время декодирования, опоздания, память), `/gifcheck?file=&n=` (CRC кадров
  без вывода на экран — сравнивается с декодированием того же файла на ПК).
- Список файлов перечитывается после `/doUpload`, `/delete`, `/set?clear=` и изменения настроек альбома;
  если папка прочиталась пустой (веб-задача в этот момент читает её же), повтор, затем каждые 5 с.
- Чтение файла для декодера дочитывает короткие ответы LittleFS (библиотека считает их концом файла,
  `GIF_EARLY_EOF`); при ошибке декодера файл открывается заново, а не замирает на последнем кадре.

### Погода

- Данные: **Open-Meteo** по HTTP, без ключа (`api.open-meteo.com` — текущая погода и макс./мин. за день),
  координаты и украинское название — геокодер `geocoding-api.open-meteo.com` по `city.json` `cd1` (кэшируется,
  пока город не меняется). Числовой код города OpenWeatherMap требует ключа OWM — тогда «потрібна назва міста».
  Ключ OWM из `key.json` пока не используется.
- Обновление раз в `city.json` `w_i` минут (минимум 5), при ошибке — раз в минуту; только если приложение включено.
  Загрузки погоды и тревог не идут одновременно (`net::fetchLock`). Ответы читаются с HTTP/1.0 (без chunked),
  JSON разбирается прямо из потока.
- Экран (макет сначала собирается на ПК теми же шрифтами): поля 12 px, две колонки по 108 px с центрами x 66 и 174.
  Верх: иконка по коду WMO (солнце/луна, облака, дождь, снег, туман, гроза) | температура 56 px с кольцом-градусом
  и под ней «як 4°» (ощущаемая). Середина: описание по-украински по центру на всю ширину (24 px; если не
  помещается — 15 px; при ошибке загрузки — текст ошибки жёлтым). Тонкий разделитель. Низ: влажность (капля)
  | ветер (три линии), каждый по центру своей колонки: значение 24 px, единица 15 px. Без города, времени,
  давления и макс./мин. Единицы — `unit.json`: °C/°F, м/с / км/год / миль/год.
- В правом верхнем углу крошечный значок Wi-Fi (`widgets.h`, 13×10 px): мигает, пока есть связь (2 с горит, 2 с нет);
  красный и не мигает, если связи нет. Такой же значок на карте тревог (угол свободен от карты).
- `/weather.json` — текущие данные и ошибка.

### Годинник

- Сверху день недели по-украински, в центре ЧЧ:ММ (DejaVu Sans Bold 71 px, только цифры), под ним секунды (36 px),
  внизу дата.
- Настройки — как у заводской прошивки (вкладка «Час»): `timecolor.json` `hc`/`mc`/`sc` — цвета часов, минут,
  секунд (`#RRGGBB`, по умолчанию белый, `#FEBA01`, `#FF5900`); `hour12.json` `h` = 1 — 12-часовой формат;
  `day.json` `day` = 1..5 — формат даты ДД.ММ.РРРР / РРРР.ММ.ДД / ММ.ДД.РРРР / ММ.ДД / ДД.ММ (через точку).
- Перерисовка: минуты и дата — только при смене, секунды — каждую секунду с заливкой фона (без мерцания).
  Пока время не получено по NTP — «синхронізація часу…».
- «Під часом» (вкладка «Час», `clock.json` `sm`, `/set?sec_mode=0|1`): секунды или обратный отсчёт Г:ММ:СС до
  следующей смены состояния света по графику «Світло» (сегодня + завтра, если опубликован). Розовый с подписью
  «до вимкнення світла» или зелёный «до ввімкнення світла»; полчаса «можливо» считаются как свет есть.
  Нет графика на сейчас или смены в опубликованных днях — показываются секунды.

### Настройки

Экран информации, как у заводской прошивки: «Magic Box FW», версия, режим Wi-Fi (клиент / точка доступа), сеть, IP.

### 6.1. Карта тревог: экран

Без шапки: карта занимает верх экрана (y 2–162), под ней название домашнего региона и часы.

- Карта с детализацией до **районов** (136 районов после реформы 2020 г.), как на alerts.in.ua:
  - **красный** — тревога уровня red (ракеты, массированный удар) или во всей области;
  - **оранжевый** — тревога уровня yellow (дроны);
  - **тёмно-зелёный** — тревоги нет;
  - **серый** — источник не прислал данных по региону (например, ubilling не отдаёт Крым).
- Районы показываются для Klymenko и NEPTUN. ubilling и alerts.in.ua (IoT) отдают только области — тогда
  область закрашивается целиком: красный — вся, оранжевый — часть.
- Рисуются только границы областей (чёрные) и обводка домашнего региона (белая); районы только закрашиваются
  цветом своей тревоги, их границы не рисуются.
- Проекция Меркатора (как карты в браузере). Вершины хранятся с точностью 1/8 пикселя (`MAP_FIX`), заливка —
  по центрам пикселей, поэтому форма не искажается округлением, а соседние районы стыкуются без щелей.
- Как на официальной карте (ukrainealarm): если тревога во **всех районах** области, область считается под тревогой целиком.
  Число районов по областям зашито в `alerts_parse.cpp` (реформа 2020 г.).
- Домашний регион обведён белым.
- **Часы** — жирным 45 px (шрифт только из цифр) в чёрной области ниже Одессы и левее Крыма (x < 148,
  y 145–187 — проверено, что там нет пикселей карты); цвет выбирается во вкладке «Тривоги», по умолчанию белый.
- **Город** (обласной центр домашнего региона; для Киевской — «Київщина») — в нижней строке, один, самым крупным
  шрифтом DejaVu Sans Bold, при котором он помещается в 234 px, но не больше 40 px (Полтава — 40 px,
  Івано-Франківськ — 22 px; `tools/gen_city_fonts.py`, каждый размер — только буквы своих городов, ~53 КБ).
  Цвет — статус региона: зелёный — тревоги нет, оранжевый, красный, серый — нет данных.
- Только при проблеме: мелко жёлтым справа, под Крымом — ошибка загрузки или `дані з ЧЧ:ММ`, если данные
  не обновлялись дольше 3 интервалов. Счётчика регионов нет (его путали с датой).
- Нет Wi-Fi дольше 15 с: вся карта и название города серые (старые данные могут быть неверны), справа
  `без мережі`. Когда связь вернётся, карта сразу перерисуется в цвета последних данных и обновится при следующей загрузке.
- Карта рисуется в 8-битный спрайт 240×160 (38 КБ), без мерцания.
- **Цвет домашнего региона** (название под картой, сигнал) — по цвету тревоги на карте: красный, если в регионе
  есть красный район (или тревога на всю область без районных данных), оранжевый — только жёлтые районы,
  зелёный — тревоги нет, серый — нет данных. Поэтому «жёлтая тревога во всех районах» — оранжевая, а не красная.
- **Сигнал — на любое новое сообщение о тревоге в домашнем регионе:** в любом его районе объявлена тревога,
  в любом районе оранжевая стала красной, а для источников без районных данных — тревога в регионе появилась
  или усилилась (сравнение с предыдущей загрузкой; отбой сигнал не вызывает). Устройство
  переключается на карту тревог и 10 с мигает (0,5 с цвет тревоги — красный 255,0,0 или оранжевый — с надписью
  «ТРИВОГА» и названием города / 0,5 с карта). Первые данные после включения сигнал не вызывают.
  Проверка: `GET /alerts/test?level=2` (красный) или `level=1` (оранжевый), кнопки во вкладке «Тривоги».

### 6.2. Карта тревог: данные

Загрузка — в отдельной задаче FreeRTOS на ядре 0, раз в `i` секунд (минимум 15), только если приложение включено.

| `src` | URL | Токен | Уровни |
|---|---|---|---|
| `klymenko` (по умолчанию) | `https://vadimklimenko.com/map/statuses.json` | нет | вся область / районы / нет |
| `neptun` | `https://neptun.in.ua/api/v1/alerts` | нет | вся область / районы / нет |
| `ubilling` | `https://ubilling.net.ua/aerialalerts/` | нет | есть / нет |
| `alertsinua` | `https://api.alerts.in.ua/v1/iot/active_air_raid_alerts_by_oblast.json` | да (`api@alerts.in.ua`) | A / P / N |

- NEPTUN: в `raions` уровни `red` (ракетная угроза) и `yellow` (угроза дронов) — обе считаются тревогой.
  По условиям использования (`/api-terms`) рядом с данными нужна видимая ссылка на neptun.in.ua,
  и сервис должен указывать, что это не официальная система оповещения. Опрос не чаще раза в 5 с.
- Ссылки на источники (в т.ч. обязательная для NEPTUN) и предупреждение о неофициальности — только в веб-интерфейсе, на экране устройства их нет (решение владельца).
- `alerts.com.ua` не используется: данные устарели (последние изменения в 2025 году).
- HTTPS без проверки сертификата: на устройстве нет набора корневых сертификатов, данные публичные и только для чтения.
- Ответы (Klymenko ~23 КБ, NEPTUN, ubilling) разбираются **прямо из потока** (`netreader.h`, HTTP/1.0) через
  фильтр: строка ответа целиком плюс документ ArduinoJson не помещались в память (`NoMemory`, самый большой
  свободный блок ~39 КБ при работе задач погоды и отключений). alerts.in.ua IoT (29 байт) читается строкой.
- Регионы везде нумеруются в порядке alerts.in.ua IoT (0 — АР Крым … 26 — Черниговская),
  районы — по таблице `RAION[]` (отсортирована по области и названию).
- Районы сопоставляются: Klymenko — по названию (текущее, включая переименования 2024 г., или старое),
  NEPTUN — по ключу (`key`). Уровень района: `alert_level`/`level` = `yellow` → дроны, иначе красный.
  Область = FULL, если тревога во всех её районах (число районов берётся из `RAION[]`), иначе PARTIAL.
- `/alerts.json`: `{"levels":"NPAU…"(27),"raions":"NYRI…"(136),"updated":<UTC>,"error":"","src":"klymenko","home":16}`
  (`raions`: N — нет, Y — yellow, R — red, I — источник без районов).
- Парсеры проверяются на ПК: `test/alerts_parse_test.cpp`.

### 6.3. Карта тревог: настройки

Вкладка **«Тривоги»** в веб-интерфейсе, файл `/.sys/alerts.json`:
`{"src":"klymenko","token":"","i":30,"home":16,"cc":"#ffffff"}`; `cc` — цвет часов под картой (`/set?al_cc=`).

Контуры областей и районов: neptun.in.ua `oblasts.geojson` и `raions.geojson` (один источник, границы
совпадают); производные OpenStreetMap, лицензия ODbL 1.0, © участники OpenStreetMap. Таблица соответствий районов —
`data-src/raions_meta.json`.

## 7. Сеть

- **Wi-Fi:** STA с данными из `/.sys/config.json` `{"a":ssid,"p":pass}`; в NVS ничего не пишется.
- **Запасная точка доступа:** открытая сеть `SmallTV-PRO` по адресу 192.168.4.1, с captive portal. Включается, если Wi-Fi не подключился за 20 с или связь пропала больше чем на 2 мин. Выключается, когда Wi-Fi вернулся и к точке никто не подключён.
- **Время:** NTP (сервер из `ntp.json`, плюс `pool.ntp.org`, `time.windows.com`). `tz.json` `mode:0` (Auto) — Europe/Kyiv с переходом на летнее время (`EET-2EEST,M3.5.0/3,M10.5.0/4`); `mode:1` — фиксированное смещение `offset` минут.

## 8. Название и язык

- Название прошивки: **Magic Box FW** (`/v.json`, заголовок и шапка веб-интерфейса, копирайт в подвале
  «Copyright © Magic Box FW. All rights reserved.»).
- Запросы к источникам тревог идут с User-Agent настольного Chrome (часть сервисов отклоняет неизвестных клиентов).
- Модель железа (`GeekMagic SmallTV-PRO`), имя в сети `smalltv-pro` и точка доступа `SmallTV-PRO` не меняются.

- Все надписи на экране и в веб-интерфейсе — на украинском.
- Экран: сглаженные шрифты DejaVu Sans 15 px и DejaVu Sans Bold 24 px (латиница + украинская кириллица),
  плюс шрифты «город + часы» (см. 6.1),
  генерируются `tools/gen_vlw.py` в `src/fonts/`; `useFont()` переключает их и встроенные шрифты TFT_eSPI
  (шрифт 7 — крупные цифры). Лицензия DejaVu (Bitstream Vera) разрешает встраивание.
- Веб-интерфейс: заводская страница переводится при сборке `tools/ui_i18n.py` (словари для текста разметки,
  атрибутов и строк JS). Строки после `name:`/`key:` не переводятся — это значения для API
  (например, `/set?open_app=Clock`). В переводах используется апостроф ’, а не ', чтобы не ломать JS.
- Страница `/update` прошивки — по-английски (служебная).

## 9. Экран и яркость

- Яркость 0–100% из `brt.json`.
- Ночной режим: с `t1` до `t2` часов яркость `b2`, если `en=1`.
- При загрузке: подсветка выключена, пока идёт инициализация; калибровка сенсора с надписью «Don't Touch Top!».
