# Magic Box FW

Своя прошивка для **GeekMagic SmallTV Pro** (ESP32, экран 240×240). Повторяет заводские приложения, настройки
и веб-интерфейс и добавляет:

- карту воздушных тревог Украины с районами;
- график отключений света;
- украинский язык.

Прошивается только по воздуху (OTA). Документы:

| Документ | Что в нём |
|---|---|
| [SPEC.md](SPEC.md) | Техническое задание и подробное описание устройства прошивки |
| [ІНСТРУКЦІЯ.md](ІНСТРУКЦІЯ.md) | Инструкция для пользователя (на украинском) |

## Возможности

| Экран | Что показывает |
|---|---|
| Повітряні тривоги | Карта областей и районов. Сигнал при тревоге в своём регионе. Автопереключение на карту. Серая карта без сети |
| Світло | Спираль графика отключений на сутки. Официальный сайт Полтаваобленерго или копии данных других обленерго. График на завтра |
| Годинник | Время, дата, день недели. Вместо секунд можно показывать отсчёт до отключения или включения света |
| Погода | Open-Meteo, без ключа |
| Біткоїн | Пары Binance: 4 макета, свечи или линия, прокрутка пар |
| Картинки | JPG и GIF, слайд-шоу |
| Налаштування | Версия, режим Wi-Fi, сеть, IP |

**Wi-Fi.** Устройство помнит 5 последних сетей и подключается к самой сильной из доступных. Если сети нет,
открывает точку доступа `SmallTV-PRO` по адресу 192.168.4.1.

**Сенсор:**
- одно касание — следующий экран;
- двойное — предыдущий;
- долгое — действие на экране: график на завтра, следующая картинка, следующая пара.

## Служебные ссылки устройства

Ниже `http://<IP>`, например `http://192.168.210.37`.

### Интерфейс и обслуживание

| Ссылка | Назначение |
|---|---|
| `/` | Веб-интерфейс: заводской, переведён, со вкладками «Тривоги» и «Світло» |
| `/update` | Обновление прошивки (OTA): страница загрузки `.bin`, POST — сама прошивка |
| `/v.json` | Модель и версия: `{"m":"GeekMagic SmallTV-PRO","v":"Magic Box FW x.y.z"}` |
| `/sys.json` | **Диагностика:** время работы, память, причина перезагрузки, «крошки» задач, журнал 10 загрузок со стеком паники |
| `/state.json` | Какое приложение на экране |
| `/touch.json` | Сенсор: текущее значение, уровень покоя, порог, счётчики касаний |
| `/space.json` | Свободное место в LittleFS |
| `/flash?offset=&size=` | Сырой дамп флеш-памяти (бэкап) |

### Данные приложений

| Ссылка | Назначение |
|---|---|
| `/alerts.json` | Тревоги: уровни областей и районов, источник, время, ошибка |
| `/alerts/test?level=2` | Проверить сигнал тревоги (`1` — частичная, `2` — полная) |
| `/outage.json` | График света: очередь, получасы сегодня и завтра (`+` есть, `-` нет, `?` возможно), ошибка |
| `/weather.json` | Погода и ошибка загрузки |
| `/btc.json` | Біткоїн: пары, цены, изменение, число свечей, неизвестные пары, ошибка |
| `/pic.json` | Картинки: файл, кадры GIF, время декодирования, память |
| `/gifcheck?file=&n=` | Контрольные суммы первых `n` кадров GIF без вывода на экран (сверка с ПК) |

### Wi-Fi

| Ссылка | Назначение |
|---|---|
| `/wifi.json` | Поиск сетей |
| `/wifisave?s=<сеть>&p=<пароль>` | Сохранить сеть и перезагрузиться |
| `/wifiknown.json` | Запомненные сети (без паролей) и текущая |
| `/wififorget?s=<сеть>` | Забыть сеть |

### Файлы

| Ссылка | Назначение |
|---|---|
| `/filelist?dir=/image` | Список файлов |
| `POST /doUpload?dir=/image` | Загрузка файла |
| `/delete?file=/image/a.gif` | Удаление |
| `/.sys/<имя>.json` | Файлы настроек, например `/.sys/alerts.json`, `/.sys/outage.json`, `/.sys/coin2.json`, `/.sys/wifis.json`, `/.sys/boots.json` |

### Управление: `/set`

Ответ на успешный запрос — `OK`. Все параметры и файлы, в которые они пишутся, перечислены в [SPEC.md](SPEC.md),
раздел 5. Часто нужные:

| Ссылка | Действие |
|---|---|
| `/set?open_app=Alerts` | Открыть приложение. Есть `Alerts`, `Outage`, `Clock`, `Weather`, `BitCoin`, `Picture`, `Settings` |
| `/set?page=1` / `page=-1` | Следующий или предыдущий экран |
| `/set?enter=-1` | Как долгое касание |
| `/set?app_bitcoin=1` | Включить приложение (`0` — выключить) |
| `/set?reboot=1` | Перезагрузка |
| `/set?al_home=16&al_auto=2` | Регион тревог (индекс), автопереключение (`0` выкл., `1` вся Украина, `2` свой регион) |
| `/set?out_src=poe&out_grp=1.1` | Источник и очередь графика света |
| `/set?sec_mode=1` | Часы: отсчёт до смены света вместо секунд |

## Сборка и прошивка

Нужен PlatformIO. Проект: `custom-fw/firmware`.

```sh
cd custom-fw/firmware
pio run                                   # сборка: .pio/build/smalltv-pro/firmware.bin
curl -F "update=@.pio/build/smalltv-pro/firmware.bin" http://192.168.210.37/update
```

Ответ `Update Success! Rebooting...` значит, что прошивка записана. Через 20–30 секунд проверьте версию на `/v.json`.
Если устройство сбросило соединение, повторите загрузку. Ни настройки, ни сети, ни картинки при обновлении
не теряются.

**Откат на заводскую прошивку:** загрузите через `/update` заводской `.bin` из папки `firmware/` этого репозитория.

### Тесты на ПК

```sh
cd custom-fw/firmware
g++ -std=c++17 -Isrc -I.pio/libdeps/smalltv-pro/ArduinoJson/src test/poe_parse_test.cpp src/outage_parse.cpp -o poe_test
./poe_test page.html   # page.html — сохранённая страница poe.pl.ua/customs/dynamicgpv-info.php
```

Аналогично собираются `test/alerts_parse_test.cpp` и `test/outage_parse_test.cpp`.

## Диагностика

Если устройство перезагрузилось само, откройте `/sys.json`.

**`boots`** — журнал последних загрузок. У записи после сбоя есть такие поля:
- `reason` — причина: `panic`, `task watchdog` и т. п.;
- `ui`, `web`, `fetch` — что в этот момент делали экран, веб-сервер и фоновые загрузки;
- `minHeap` — минимум свободной памяти;
- `panic`, `task` — тип ошибки и задача, в которой она случилась;
- `bt` — адреса стека.

Чтобы расшифровать адреса, нужен `firmware.elf` той же сборки:

```sh
~/.platformio/packages/toolchain-xtensa-esp32/bin/xtensa-esp32-elf-addr2line -pfiaC \
  -e custom-fw/firmware/.pio/build/smalltv-pro/firmware.elf <адреса из bt>
```
